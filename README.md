# 3D Kamron — программы для магазина

Две отдельные программы для двух ноутбуков (собираются из одного репозитория):

| Программа | Для чего | Файл |
|---|---|---|
| **3D Kamron Показ** | ноутбук с телевизором: показать клиенту комнату в 3D, посчитать, напечатать накладную | `3D-Kamron-Pokaz.exe` |
| **3D Kamron Заказы** | ноутбук для заказов с сайта: окно заказов, уведомления в углу экрана, запуск вместе с Windows | `3D-Kamron-Zakazy.exe` |

## 3D Kamron Заказы
- Впишите адрес сайта и адрес админки в Настройках.
- «Открыть заказы» → войдите паролем → «🔔 Включить уведомления». Дальше каждый новый заказ
  всплывает в углу экрана, даже если окно закрыто. В заказе — подтверждение в WhatsApp/Telegram
  с готовым сообщением и реквизитами.
- «Запускать вместе с Windows» — включили ноутбук, заказы уже открыты.

## 3D Kamron Показ

Программа для ноутбука в магазине: показывает клиенту его комнату в 3D (в том числе на телевизоре),
считает плитку и коробки, печатает расчёт. Конструктор тот же, что на сайте магазина,
поэтому клиент в магазине и клиент на сайте видят одно и то же.

## Что умеет
- **3D-конструктор**: ванная, туалет, кухня, комната и коридор, цоколь и двор; пол любой формы
  (короба, ниши, скосы, коридор, проёмы и двери); виды «Обзор», «Сверху», «Изнутри».
- **Плитка**: общая на стены, отдельная на каждую стену, нижняя зона, акцентная стена, пол;
  раскладки прямая, вразбежку, по диагонали; затирка и ширина шва; поиск по названию и размеру.
- **Расчёт**: площадь, штуки, коробки, сумма; пол — по настоящей раскладке, с подрезкой.
- **Печать накладной** (A5) как в прежней версии: «НАКЛАДНАЯ», материалы по каждой стене, итог к оплате,
  «Спасибо за выбор 3D Kamron!» — плюс картинка комнаты. Печатает сама программа (PDF), шрифт встроен,
  интернет не нужен. Кнопка «Печать расчёта» в конструкторе.
- **Языки**: русский и узбекский (кнопка UZ / RU).
- **ТВ**: «Показать на телевизоре» открывает окно на весь экран; ▶ — презентация с вращением,
  → — встать внутри комнаты, ← — обзор, Esc — выход.
- **Каталог**: пока нет сайта — ведётся в программе (как раньше «Админ панель»: название, размер,
  цена, фото, наличие). Когда сайт работает — впишите его адрес в Настройках, и программа будет
  брать каталог с сайта и помнить его без интернета.
- Плитка из старой версии программы переносится автоматически при первом запуске
  (проверьте у неё «м² в коробке» и стиль).

## Как устроено
- **Написано на Flutter (Dart).** Программа (Windows) запускает внутри себя маленький веб-сервер на `127.0.0.1`
  и открывает конструктор в отдельном окне Microsoft Edge без адресной строки
  (Edge есть в каждой Windows 10/11). Интернет для работы не нужен.
- `assets/web/` — копия сайта (без админки), тот же конструктор. Обновить: `tool/sync_web.sh ../tile-shop-site`.
- `lib/services/local_server.dart` — сервер: конструктор, каталог (свой или с сайта + кэш), фото.
- `lib/services/catalog_store.dart` — свой каталог (`catalog.json` и папка `images`
  в `%APPDATA%`), перенос из старой базы.
- `lib/services/browser_launcher.dart` — запуск окна Edge/Chrome.

- `lib/main.dart` — «Показ», `lib/main_orders.dart` — «Заказы».

## Сборка
GitHub Actions собирает обе программы при каждом пуше (вкладка Actions → артефакты
«3D-Kamron-Pokaz-Windows» и «3D-Kamron-Zakazy-Windows»). Локально:
`flutter build windows --release -t lib/main.dart` и `flutter build windows --release -t lib/main_orders.dart`.
